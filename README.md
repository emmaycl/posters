# Posters

This repository contains selected research posters/slides by **Emma Yicheng Lou** as part of her academic portfolio.

* [**Emma_poster_Edmondson2023.pdf**](./Emma_poster_Edmondson2023.pdf): Poster presenting proteomic biomarker discovery for early sepsis detection using MALDI-TOF mass spectrometry.
* [**Emma_poster_MDA24.pdf**](./Emma_poster_MDA24.pdf): Poster presenting evaluation and enhancement of a digital pathology model using multimodal data and spatial transcriptomics.
* [**Emma_Slides_MSK2025.pdf**](./Emma_Slides_MSK2025.pdf): Slide presentation on task-agnostic evaluation of self-supervised learning embeddings. 
* [**LogM_Poster_Latest.pdf**](./LogM_Poster_Latest.pdf): Poster presenting an algorithmic framework for comparing weak orders between translation-invariant total orders (TITOs). The work includes inversion set decomposition, normalization of window notation, comparison algorithms, Hasse diagram visualizations, and Join computation. Authors are listed alphabetically.
